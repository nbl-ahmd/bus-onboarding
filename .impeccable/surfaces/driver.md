# Driver workspace

Mode: Operate. Existing product refined at the user's request using gpt-taste. The user explicitly prioritizes simplicity and minimal taps over the skill's marketing-page choreography.

## Direction contract
THESIS: One tap plays a prepared announcement's whole language sequence. Details are a separate edit action, never a compulsory second screen.
OWN-WORLD: Existing blue/sea-green palette, locally bundled Outfit for English and Noto Sans Malayalam for Malayalam, compact white rows, familiar navigation and a restrained route strip.
STORY: Confirm trip once, save playback order/repeats once, then tap an announcement. Edit or hold a row to change facts. Player always exposes Stop, language and part count.
FIRST VIEWPORT: Slim brand/navigation header, short Announcements heading, compact trip strip, Favourites/All selector and language-sequence control, four common rows in a two-column desktop grid or mobile list. Mobile bottom navigation; details in a right sheet or full-screen mobile editor.
FORM: gpt-taste deterministic local run seed 300 selected Editorial Split, Outfit, and component/motion examples. The split is list plus optional editor; title/row/sheet transitions use GSAP and honor reduced motion. The user's task-first instruction overrides the marketing AIDA, imagery, marquee and scroll-pinning recipes. No imagery is needed for a driver control surface.
FINISH: Check the actual phone and desktop render, both repeat orders, one-tap playback, gesture cancellation and existing offline behavior. Keep DESIGN.md and sidecar aligned with the shipped controls.
