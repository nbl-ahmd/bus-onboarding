# Asset provenance

- `public/icons/icon.svg`: original geometric Nightline working-mark authored in this project; no third-party brand asset or source image used.
- `public/icons/icon-192.png` and `icon-512.png`: rasterized from that SVG using Sharp at the stated dimensions; installation icons only, not AI-generated artwork.
- Interface icons: Lucide, installed from the npm package and rendered as SVG.
- English headings and branding: Outfit 400/500/600, installed via Fontsource and bundled locally.
- Malayalam type: Noto Sans Malayalam, installed via Fontsource and bundled with the application. No remote font request is needed for offline rendering.
- No stock photographs, sourced illustrations, voice cloning, or pre-generated passenger speech is shipped.
